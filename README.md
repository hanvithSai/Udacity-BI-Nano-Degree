## Project 1 — From College Boards to Dashboards: Student Enrollment Analysis

### Project overview

- **Goal:** Use Amazon QuickSight to analyze student enrollment, evaluation scores, costs, and related factors to recommend ways to improve student satisfaction without increasing course costs.
- **Deliverables:** Dataset, Q topics, verified Q answers, dashboard(s), scenario(s), data story, and screenshots for submission.

### Implementation overview

- Prepare and publish a cleaned enrollment dataset in QuickSight, including required calculated fields and renamed attributes.
- Build analyses and visuals that support Q topics and automated insights; create a dashboard exposing Q&A.
- Configure a Q Topic with Named Entities, verify answers, and assemble a scenario and executive data story summarizing recommendations.

### Deliverables checklist

- Dataset(s) uploaded and published (with refresh schedule).
- Calculated fields and renamed fields documented.
- Analysis file(s) with visuals and sheets.
- Published Dashboard "Student Enrollment Dashboard" with Q&A enabled.
- Q Topic: "Regional Community College Student Data" with Named Entities and verified answers.
- At least three Verified Q answers with notes and AI-suggested follow-up prompts.
- Scenario demonstrating a typical stakeholder workflow.
- Data Story with slides for executives and screenshots for submission.

## Project 2 — CareerCoachAssistant — AI-powered Career Coach App

### Project overview

- **Goal:** Build a reusable Q App that helps learners assess skill gaps and receive personalized career recommendations using resume input and course catalog data.
- **Deliverables:** Q App package (screenshots, export), documentation, usage demo, and code snippets (if any integrations used).

### Implementation overview

- Assemble a small course catalog and anonymized example inputs; optionally host data in S3/DynamoDB for app reference.
- Design a no-code Q App UI with inputs for resumes/target role/budget and outputs for gap analysis and prioritized course recommendations.
- Implement simple matching logic (skill overlap scoring with constraints), test with example resumes, refine prompts, publish and document the app.

### Deliverables checklist for Project 2

- Q App: "CareerCoachAssistant" published and tested.
- Example inputs (resumes) and expected outputs.
- Documentation of matching logic, constraints, and sample prompts.
- Screenshots or short screencast demonstrating the app.
